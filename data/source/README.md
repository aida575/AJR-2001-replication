# Source data for `AJR_section5_results.ipynb`

All files are stored as downloaded (November 2026). The notebook reads only these files.

| File | Content | Source |
|---|---|---|
| `ajr/maketable1.zip`, `ajr/maketable2.zip`, `ajr/maketable4.zip` | AJR (2001) replication files (Stata `.dta` and `.do`): institutions (`avexpr`), 1995 income (`logpgp95`), settler mortality (`logem4`, `extmort4`), base sample (`baseco`) | Daron Acemoglu's data archive, https://economics.mit.edu/people/faculty/daron-acemoglu/data-archive |
| `maddison2023_web.dta` | Maddison Project Database 2023: GDP per capita (2011 international $), 1820–2022 | https://dataverse.nl/api/access/datafile/421303 |
| `wdi_NY.GDP.PCAP.KD.json` | World Bank WDI: GDP per capita, constant 2015 US$, 1960–2025 | https://api.worldbank.org/v2/country/all/indicator/NY.GDP.PCAP.KD?format=json&per_page=20000&date=1960:2025 |
| `wdi_NY.GDP.PETR.RT.ZS.json` | World Bank WDI: oil rents, % of GDP, 1960–2025 | https://api.worldbank.org/v2/country/all/indicator/NY.GDP.PETR.RT.ZS?format=json&per_page=20000&date=1960:2025 |
| `wb_countries.json` | World Bank country metadata: capital city coordinates | https://api.worldbank.org/v2/country?format=json&per_page=400 |
| `imf_NGDP_RPCH.json` | IMF World Economic Outlook: real GDP growth (%) | https://www.imf.org/external/datamapper/api/v1/NGDP_RPCH |
| `imf_LP.json` | IMF World Economic Outlook: population | https://www.imf.org/external/datamapper/api/v1/LP |
